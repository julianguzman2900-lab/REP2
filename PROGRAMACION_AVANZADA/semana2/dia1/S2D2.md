# Práctica node, js, html, css
Desarrollar una aplicación web interactiva que simule la solicitud de un crédito personal.

## Requisitos
### Frontend
- Crea simulador.html dentro de public. Debe solicitar: Nombre del Solicitante, Ingreso Mensual (en números) y Monto Solicitado.
- Crea banco.css para diseñar una interfaz limpia, utilizando colores del sector financiero (azules oscuros, grises y blanco).
### Validación del Cliente

* El script del cliente debe verificar que el Monto Solicitado no sea mayor a 10 veces el Ingreso Mensual. Si el usuario rompe esta regla, se debe detener el envío del formulario y mostrar una alerta informando que el monto excede su capacidad de endeudamiento

## Backend

* Configura tu servidor en app.js usando Express.
* Crea la ruta POST hacia /evaluar-credito.
* El servidor debe recibir los datos, calcular el porcentaje que representa el monto respecto al salario para la bitácora interna e imprimir un reporte detallado en la terminal.
* Finalmente, responderá enviando el archivo físico aprobado.html usando res.sendFile().
