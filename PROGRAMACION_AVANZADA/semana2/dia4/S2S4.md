# Secuencial vs Paralelo
## Secuencial
```js 
async function secuencial() {
    const a = await tarea(5000);
    const b = await tarea(6000);
    
}

```

## Paralelo 
```js
async function paralelo() {
    const p1 = tarea(5000); // inicia de inmediato
    const p2 = tarea(3000); // inicia de inmediato
    const [promesa1, promesa2] = await Promise.all( [p1,p2] ) // esperar a ambas promesas 

    console.log(promesa1, promesa2)

}
```

###  Regla de oro: 
si una tarea no depende de la otra, podemos usar `Promise.all`


## qué es Promise.all?

recibe un **iterable** (normalmente un array) de promesas y devuelve **una nueva promesa** que:
- **Se resuelve** cuando **todas** las promesas del iterable se **resuelven con éxito**.
- **Se rechaza** en cuanto **una sola** de las promesas del iterable se **rechaza** (comportamiento **fail-fast**).


cuando se resuelve con éxito, el **resultado** es un **array** con los valores de cada promesa, **en el mismo orden** del iterable original (no en el orden de finalización).



```js
const p1 = Promise.resolve(1);
const p2 = Promise.resolve(2);
const p3 = Promise.resolve(3);

Promise.all([p3, p2, p1])
  .then(([r1, r2, r3]) => {
    console.log(r1, r2, r3); // 1 2 3
  })
  .catch(err => console.error("Alguna falló:", err));
```


### Ejemplo
```js
function tarea(ms, nombre) {
    return new Promise( res => {
        setTimeout( () => res(`${nombre} lista en ${ms} ms`), ms )
    } )

    console.log(promesa4)

ejemploAll();
```

### Qué ocurre si una falla?

```js
function tareaConError(ms, falla) {
    return new Promise( (resolve, reject) => {
        setTimeout( () => {
            if (falla)
                reject(new Error(`Fallé en ${ ms }`))
            else
                resolve(`OK en ${ms} ms`)
        })
    } )
}

async function ejemploError() {
    const promesa1 = tareaConError(3000, false);
    const promesa2 = tareaConError(4000, true); // esta fallará
```

## diferentes tipos de promesas 

* `Promise.allSettled`: Útil cuando quieres **todos los resultados**, incluso de las que fallan.

```js
const p1 = tareaConError(200, false);
const p2 = tareaConError(300, true);
const r = await Promise.allSettled([p1, p2]);
console.log(r)
// r = [ {status:"fulfilled", value:"Ok en 200 ms"}, {status:"rejected", reason: Error(...) } ]
```

* `Promise.race`
Útil para **timeouts** o para quedarte con el **primer** resultado que llegue (bueno o malo).
```js
function timeout(ms) {
  return new Promise((_, rej) => setTimeout(() => rej(new Error("Timeout")), ms));
}
const primero = await Promise.race([tarea(500, "A"), timeout(300)]);
// Si timeout gana → lanza error; si A llega antes → devuelve A
```

* `Promise.any`
Útil cuando **con una exitosa basta** (por ejemplo, consultar varios mirrors).
